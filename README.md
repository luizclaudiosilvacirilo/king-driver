# King Driver 👑

Aplicativo de mobilidade urbana para Sabará/MG, com acesso para passageiros e motoristas.

## QR Codes e convite

- `qr.html`: página pública com QR Code de download e QR Code do grupo de motoristas.
- `download.html`: inicia o download do APK publicado pelo projeto e tenta abrir o grupo do WhatsApp em seguida.
- O aplicativo Android também exibe os dois QR Codes na tela de acesso e na tela principal.
