# King Driver — Sabará/MG

## Projeto próprio

O repositório `luizclaudiosilvacirilo/king-driver` é o repositório GitHub próprio usado como fonte do aplicativo.

## Código-base

O código da aplicação fica versionado neste repositório. O frontend PWA pode ser instalado no Android pelo navegador e o backend é servido pela estrutura `api/`.

## MVP

- Passageiro: cadastro, login, solicitar corrida, consultar histórico e perfil.
- Motorista: cadastro, login, veículo, online/offline, aceitar/gerenciar corrida e carteira.
- Proprietário: área administrativa básica.
- Localização: preparação para integração de GPS/mapas.
- Pagamento: estrutura preparada para integração; transações reais exigem gateway e credenciais seguras.

## Operação real

Antes de disponibilizar publicamente para corridas reais, devem ser configurados banco/autenticação, RLS, mapas/GPS, notificações, pagamentos, validação de motoristas, segurança e requisitos legais aplicáveis.
